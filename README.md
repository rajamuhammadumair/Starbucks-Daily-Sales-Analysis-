# ☕ Starbucks Daily Sales Analysis Dashboard

An interactive Power BI dashboard that analyses Starbucks daily sales data to uncover insights into revenue performance, product sales, customer purchasing patterns, and sales trends through dynamic visualisations.

---

## 📌 Project Overview

This project showcases an interactive Power BI dashboard designed to analyse Starbucks daily sales data. The dashboard enables users to explore sales performance, identify popular products, analyse revenue trends, and gain actionable business insights through interactive reports and visualisations.

---

## 🎯 Objectives

- Analyse daily sales and revenue performance.
- Identify top-performing products.
- Explore customer purchasing patterns.
- Analyse sales trends over time.
- Compare product and category performance.
- Build an interactive dashboard for retail sales analysis.

---

## 📊 Dashboard Features

- Interactive filters and slicers
- Daily sales analysis
- Revenue performance tracking
- Product performance analysis
- Sales trend visualisation
- Category-level analysis
- KPI cards
- Interactive charts and graphs
